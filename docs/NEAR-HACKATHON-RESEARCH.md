## The pattern

1. **NEAR's own technology is the core, not a sticker.** NFTs that open doors (3FIT, Burrito pets), BOS, Shade Agents, Intents and Chain Signatures carry the product.
2. **One flow works end to end, live, with on-chain proof.** Judges can click it and then see the contract and the transaction.
3. **One-sentence utility.** "A no-code dApp builder", "a subscription agent", "a gym pass as an NFT".
4. **It feels like a consumer app.** Chat interfaces, web-style sign-in, and speed on ordinary phones (PlunderLand's 60 FPS was called out).
5. **Games win on the loop.** PlunderLand's loop is pay in → gather → risk → cash out; the economy serves the loop. The current NEAR Hackathon says it outright: Games With Real Economies is "judged on the game loop, not the token".
6. **It keeps going.** NEAR's Protocol Rewards look at on-chain metrics, code activity and traction, not the pitch.

The current hackathon (Nov 2026) adds two practical rules: an AI first checks that each project runs and does what its README says, and a public post on X tagging @NEARProtocol with #NEARHackathon and a demo is required.

## Suggestions, in order

1. **Enter several tracks:** Games With Real Economies, NFTs That Do Something, and Agent Economy (the rules allow more than one).
2. **Keep the README exact.** It is checked against the running game: every claim should match what a judge can click.
3. **Post the trailer on X** with #NEARHackathon and @NEARProtocol before 14 Nov, 23:59 UTC (required).
4. **Agents that play for their owners**, as a NEAR AI or Shade Agent, for the Agent Economy track.
5. **NEAR Intents for top-ups** from any chain (a payments change: the owner's call).
6. **Show traction**: count certificate mints and players on a public page or in the README.
7. **After the hackathon, mainnet**: certificates and the Season 1 Founder badge as mainnet NFTs.
